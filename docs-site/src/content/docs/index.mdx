  </Card>
  <Card title="Every top model, one app" icon="rocket">

  </Card>
  <Card title="Tools for any file" icon="puzzle">
    Upscale, remove a background, remove an object, restyle, relight, lip-sync, dub, transcribe and more, each with the models that can really do the job.
  </Card>
  <Card title="Your files stay yours" icon="laptop">
    Results are saved to a folder you choose. Keys are never put in a backup. Windows, macOS and Linux, and the app updates itself.
  </Card>
