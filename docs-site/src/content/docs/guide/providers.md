## Add a key

1. Open Settings, then Providers.
2. Pick a provider and paste its key into the box.
3. Press Test. A green result means the key works.
4. Switch on the models you want in the list.

Only the models you switch on appear in the model picker on Create. The first model in a chain is the main one; the rest are used if it fails.

## Which providers

- fal: many image and video models.
- Replicate: a large catalog of community and official models.
- OpenRouter: chat and text models from many makers.
- Gemini and OpenAI: their own text, image and speech models.

## Keeping a key safe

Keys are stored on this device and are never put in a backup file. Treat the device like the key: anyone who can open the app can use it. You can set a master password in Settings, General.
