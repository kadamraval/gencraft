## Make something

1. Choose what to make: image, video, audio or text.
2. Open the model picker and choose a model. The row shows what it accepts and what it costs.
3. Write the prompt and set the options the model offers.
4. Press send. You can keep sending while earlier runs are still going.

Several runs can go at once. The rest wait in line and start by themselves. You can cancel one that is waiting. The number that run together is set in Settings, General, Limits.

## The plus menu

- Upload: add your own picture, clip or sound as a reference.
- Created: reuse something you already made.
- Element: attach a saved character, place, product or look.
- Template and Liked: start from a template or a favorite.
