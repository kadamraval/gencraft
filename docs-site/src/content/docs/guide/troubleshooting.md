## A run fails

- No key: the message names the provider. Add a key in Settings, Providers.
- The key is rejected: press Test on the provider. Keys with a space or a line break at the end fail.
- A model was retired: switch to its newer version in the list.
- Out of credit: top up with the provider. The app only shows an estimate.

## Still stuck

Open Help, then Support, and use Copy details to send us what we need to look into it. It holds the version and settings but never your keys.
