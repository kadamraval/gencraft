## What is in it

Every result you generate and every file you upload is in the Library. Results are filed by project, and you can add them to your own folders.

## Disk space

The Library keeps real files. Settings, General, Limits has a warning for when the Library grows past a size you choose, so it never fills the disk without telling you.
