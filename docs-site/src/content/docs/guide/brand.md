## Make a kit

Press Add brand kit. Type a website and press Fetch to read its name and logo, or upload a logo and type the name yourself.

> Tip: Fetching a site reads the site's public home page. If a site blocks it, add the logo by hand.

## What a kit holds

- About: name, tagline, description, website and social links.
- Logo: tag each logo as Primary, Light, Dark, Light Mono or Dark Mono. The app shows the right one for the light or dark look.
- Colors and fonts: pick from any Google Font.
- Products: add many at once with names, categories and descriptions.
- Moodboard, Template and Rules.
