Release notes are added at the top by the `/release` flow, newest first. Commit messages start with `feat`, `fix`, `docs`, `chore` and so on; a `!` after the type marks a breaking change.

## v0.1.0-beta.3

First public beta. Features may change and some things are rough: please [report problems](https://github.com/kadamraval/gencraft/issues).

- Gencraft: the app, its stored data and its desktop package carry the new name; older data moves over on first start.
- One standard model database for fal, Replicate, OpenRouter, OpenAI and Gemini, rebuilt daily with coverage checks.
- Updates: the person chooses how often models and the app are checked.
